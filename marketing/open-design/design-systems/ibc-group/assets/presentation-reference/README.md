# Official presentation reference

The PNG files in this folder are rendered examples from the brand's official Powerpoint Master v1.0. The gateway also copies that original file into each project as official-master.pptx when the private master is available.

For presentations, inspect these examples before designing: slide-01 is the cover, slide-03 explains typography, and the later slides show tables, content, images and closing pages. Preserve the selected brand's Ubuntu typography, colours, logo treatment, spacing and 16:9 canvas. Adapt the reference to the user's content; never copy example dates, contacts, dummy chart values, table text or the label PPT Master into their deck. The reference is visual guidance, not factual evidence.

Use one coherent image on a cover. Do not combine two half images or reuse a services collage for a single topic.

The PowerPoint export offers two different results: the official template uses editable title and body placeholders in the standard slide layouts; the exact Studio export uses an image per page. Do not claim that images, charts or diagrams become editable in the template export.
